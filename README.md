# MMDLPC
Code and reproducibility materials for the MMDLPC study.

模型训练及论文图表的 R / Python 代码，按分析主题整理。

| 目录 | 内容 |
|---|---|
| `01_Clinical_and_Cohort` | 临床队列与临床模型 |
| `02_Radiomics` | 影像组学 |
| `03_Pathomics` | 病理组学 |
| `04_Multimodal` | 多模态融合 |
| `05_Molecular_Exploration` | 分子探究 |
| `06_Human_AI_Study` | 人机读片实验 |
| `07_Supplementary_Figures` | 补充图 |
| `08_Supplementary_Tables` | 补充表，CSV 输出 |

`modeling_pipeline.py` 为公共建模模块。
